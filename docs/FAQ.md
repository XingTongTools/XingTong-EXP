# 星瞳經驗辨識工具：常見問題

## 綁定後為什麼沒有開始計時？

綁定視窗只會啟動 EXP 預覽辨識。按下「開始」後才會歸零統計時間，並以可靠 OCR 作為本次工作階段基準。

## 為什麼顯示不支援？

程式會依選擇的遊戲與目前遊戲內容解析度判斷。請先確認遊戲選項、視窗綁定目標及正式支援表是否一致。

## OCR 數值偶爾沒有更新？

程式會過濾短暫遮擋、截圖更新中與不合理跳值。若長時間未更新，請確認 EXP 區域未被其他視窗、遊戲選單或縮放設定遮住。

## 打包版辨識異常怎麼檢查？

請確認下載的是完整主程式，並完整解壓縮；不要只複製 EXE。OCR runtime 與相依檔案位於同一個 onedir 程式資料夾內。

## 如何保存本次統計？

按下「停止」會結束並保存本次工作階段，之後可在星瞳分析艙查看，或輸出 CSV 與 PNG 圖表報告。

## 更新後設定會消失嗎？

更新器會保留使用者設定、觀測紀錄、報告與匯出資料，並在套用失敗時嘗試從備份還原。
